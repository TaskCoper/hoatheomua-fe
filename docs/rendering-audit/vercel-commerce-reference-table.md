### Files that could plausibly fit more than one type

- **`app/search/page.tsx`** - Is both a _search results_ page (when `?q=` is present) and a _full catalog listing_ page (when no query is present, shows all products). Both behaviors share one file. Classified as `listing` because the rendering pattern (product grid, sort filters) is identical in both cases; the search input just scopes the `getProducts()` query.

- **`components/cart/modal.tsx`** - Could be argued as `checkout` because it shows totals, taxes, and a "Proceed to Checkout" button. Classified as `cart` because it manages the cart state (add/remove/update quantities) and does not own the actual checkout flow; that responsibility is delegated to Shopify via `redirectToCheckout()`.
